# userscripts

Small browser userscripts for improving websites I use.

## Banking

- [HNB Online Banking – Modern OTP entry](banking/hnb-modern-otp.user.js) — replaces the small HNB login OTP field with a clear six-digit entry view and a confirmation affordance.

Install the script with a userscript manager such as Tampermonkey or Violentmonkey. It runs only on `onlinebanking.hnb.lk`; OTP values remain on that page and are not sent anywhere else by the script.
